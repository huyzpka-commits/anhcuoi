# REQUIREMENTS.md

## Project Overview
**Dũng - Việt Anh Wedding Gallery** — A luxurious, interactive wedding photography showcase website for the wedding of Dũng & Việt Anh.

The application loads photos from a `manifest.json` catalog and displays them in a beautiful gallery with visual effects. It also provides a full-featured admin interface to manage albums and upload custom images.

---

## Functional Requirements

### 1. Core Features
- Display multiple photo albums with distinct visual themes
- Masonry grid layout for the full gallery
- Beautiful image modal with:
  - Navigation (next/prev)
  - Thumbnail strip
  - Download image
  - Keyboard support (arrows + ESC)
- Parallax hero section with sparkle effects
- Wedding rings favicon and navbar branding
- Home button in navbar for quick navigation

### 2. Album Management (Admin Panel)
- Create new albums (auto-generates folder path via slugify)
- Upload multiple images to any album (supports drag & drop via file input)
- Delete albums (manifest albums protected from deletion)
- View list of all albums with photo counts and folder paths
- Toast notification on album creation with folder path

### 3. Search & Filtering
- Real-time search across all images and album names
- Filter gallery by specific album
- Dynamic filter tabs (auto-generated from manifest, flex-wrap layout)

### 4. Visual Effects
- Shine sweep animation on hover
- Sparkle particle effects
- Smooth hover transitions and scaling
- Responsive design (mobile-friendly)

### 5. Data Loading & Persistence
- Photos loaded from `manifest.json` (generated by `update-gallery.ps1`)
- Manifest albums identified with `manifest_` prefix
- User-created albums stored separately in `localStorage` (`dung_anh_user_albums`)
- Stale localStorage cleared on each load to prevent phantom albums

### 6. User Experience
- Contact modal with hotline number (0948 218 888)
- Smooth scrolling between sections
- Professional luxury aesthetic (dark theme + gold accents)
- Cache-busting on manifest fetch (`?v=Date.now()`)

---

## Non-Functional Requirements

- **Performance**: Fast loading, optimized for high-resolution images
- **Accessibility**: Keyboard navigation supported in modal
- **Responsiveness**: Works well on mobile, tablet, and desktop
- **Maintainability**: Clean JavaScript, PowerShell sync script
- **No Backend Required**: Fully client-side (GitHub Pages hosting)

---

## Technical Stack
- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- Font Awesome 6 (ring icon)
- manifest.json (photo catalog)
- localStorage (user-created albums only)
- PowerShell script for photo sync (`update-gallery.ps1`)

---

## Photo Sync Workflow
1. Add photos to subfolders under `albums/`
2. Run `update-gallery.ps1` to scan and generate `manifest.json`
3. Script auto-commits and pushes to GitHub
4. GitHub Pages deploys in 1-2 minutes
5. Albums in `$excludeAlbums` list are hidden from website
